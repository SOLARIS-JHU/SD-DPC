# sdpc package

- `systems`: the three paper systems and their dynamics and policy objectives.
- `data`, `sindy`, `training`: sampling, sparse function libraries, system ID, and policy learning.
- `eval`, `baselines`, `safety`, `plotting`: fixed-controller evaluation, MPC, constraints, and figures.
- `config`, `io`, `registry`: YAML loading, checkpoints, and system lookup.

The case-specific commands and configs are in `scripts/` and `case_studies/`.
