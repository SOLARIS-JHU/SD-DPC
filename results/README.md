# Paper results

- `system_identification/`: held-out dynamics rollouts for the three paper systems.
- `policy_sweeps/`: the policy sparsity and validation-loss sweep used for model selection.
- `policy_evolution/`: Van der Pol closed-loop policy-training animation and README preview.
- `evaluation/`: final fixed-controller trajectories, policy coefficients, and the combined controller table.

Figures are saved as both publication-quality PDF and README-ready PNG. The controller table is the saved publication output; it is not recomputed by this copy. Van der Pol is the one-input, relative-degree-two case.
